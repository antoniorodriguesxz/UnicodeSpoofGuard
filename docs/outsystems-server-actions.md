# OutSystems Server Action Reference

This reference catalogs every OutSystems server action exposed by `UnicodeSpoofGuard`, describing parameters, option interactions, and representative input/output combinations. It derives directly from the contract in `src/IUnicodeSpoofGuard.cs` and the runtime behaviour implemented by `src/UnicodeSpoofGuard.cs`, `src/Analyzer.cs`, and the supporting data services.

## Shared Structures

### `AnalysisOptions`

| Field | Type | Default | Effect on runtime |
| --- | --- | --- | --- |
| `UseStrictMode` | `bool` | `false` | When true, selects the `strict` detection profile: ASCII confusables and identical mappings are flagged because the underlying profile does not suppress them. Defaults to the `balanced` profile otherwise. |
| `Locale` | `string?` | `null` | Locale hint (IETF language tag). When populated, `PolicyConfig.Resolve` tries to match a profile whose locale list contains the hint. |
| `PolicyProfile` | `string?` | `null` | Explicit policy profile key. Takes precedence over locale resolution when provided. |
| `DisableThreatIntel` | `bool` | `false` | When true, `AnalysisContext.EnableThreatIntel` becomes `false`, preventing `ThreatIndicatorStore` lookups. Leaving it `false` keeps feed matching enabled. |

Effective overrides follow this matrix:

| `UseStrictMode` | `DisableThreatIntel` | `Locale` | `PolicyProfile` | Effective strict mode | Threat intelligence | Policy profile chosen |
| --- | --- | --- | --- | --- | --- | --- |
| `false` | `false` | `null` | `null` | Uses library default (`balanced`) | Enabled | Default profile (`global`) |
| `true` | `false` | `null` | `null` | Forces `strict` mode | Enabled | Default profile (`global`) |
| `false` | `true` | `null` | `null` | Uses library default (`balanced`) | Disabled | Default profile (`global`) |
| `true` | `true` | `null` | `null` | Forces `strict` mode | Disabled | Default profile (`global`) |
| any | any | non-null | `null` | From strict flag | Follows disable flag | First profile whose locale list matches the hint (e.g., `latin-greek` for `el-GR`) |
| any | any | any | non-null | From strict flag | Follows disable flag | Explicitly requested profile (overrides locale) |

### `AnalysisResult`

- `IsSafe` (bool) signals whether findings were produced.
- `Reason` (string) contains the description of the first finding when unsafe, otherwise an empty string. It remains `null` only in early-return shortcuts that bypass the analyzer.
- `CanonicalValue` (string) is the canonicalized text as returned by `SpoofDetector.GetCanonicalString`.
- `Findings` is the ordered list of `DetailedFinding` items.

### `DetailedFinding`

Each finding exposes:

- `FindingType`: `"Homoglyph"`, `"MixedScript"`, `"InvisibleCharacter"`, `"BidirectionalControl"`, or `"ThreatIntel"`.
- `Description`: Human-readable explanation generated by the detection step.
- `Position`: Zero-based index within the raw input.
- `Substring`: Exact slice of the input that triggered the finding.

### `RefreshConfusablesResult`

- `IsSuccess`: `true` when the refresh completes; `false` when any validation or network error occurs.
- `Message`: Success acknowledgement or the error detail.
- `SourceVersion`: Version string parsed from the dataset header (for the bundled dataset this is `17.0.0`).
- `SourceDate`: Publication timestamp from the dataset header (`2025-07-22T05:49:37Z` for the bundled file).
- `RetrievedAt`: Moment the dataset was loaded.
- `EntryCount`: Number of confusable mappings ingested (the bundled file contributes 9,981 entries).

## Server Action Catalogue

### `IsSafeEmail`

Validates email-like input and returns an `AnalysisResult`.

- Input parameters:
  - `Email` (`string`, required)
  - `Options` (`AnalysisOptions?`, optional)
- Behaviour highlights:
  - Empty or whitespace strings short-circuit to `IsSafe = true`, `Reason = null`, `CanonicalValue = null`, empty findings.
  - Non-empty inputs defer to `Analyzer.Analyze`, so the `Reason` is the first finding description when any issue is detected.
  - Canonicalisation always runs when the analyzer executes, independent of findings.

#### Example combinations

1. **Blank input (no options)**
   - Input: `""`
   - Options: omitted
   - Expected output: `IsSafe = true`, `Reason = null`, `CanonicalValue = null`, `Findings = []`

2. **ASCII address with defaults**
   - Input: `"contact@example.com"`
   - Options: omitted
   - Expected output: `IsSafe = true`, `Reason = ""`, `CanonicalValue = "contact@example.com"`, `Findings = []`

3. **ASCII confusable surfaced only in strict mode**
   - Input: `"help@goog1e.com"`
   - Options: `UseStrictMode = true`
   - Expected output:
     - `IsSafe = false`
     - `Reason = "Substring '1' at position 9 is a homoglyph of 'l'."`
     - `CanonicalValue = "help@google.com"`
     - `Findings` contains a single `Homoglyph` entry with `Position = 9`, `Substring = "1"`

4. **Same input without strict mode**
   - Input: `"help@goog1e.com"`
   - Options: omitted (defaults suppress ASCII confusables)
   - Expected output: `IsSafe = true`, `Reason = ""`, `CanonicalValue = "help@google.com"`, `Findings = []`

5. **Cyrillic homoglyph attack - visually identical to real PayPal domain**
   - Input: `"support@pаypal.com"` (Cyrillic 'а' U+0430 instead of Latin 'a' in 'paypal')
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "The text contains characters from multiple scripts: Latin, Cyrillic."`
     - `CanonicalValue = "support@paypal.com"`
     - `Findings` contains one `MixedScript` entry and likely `Homoglyph` entries for the Cyrillic characters

6. **Multi-character Cyrillic substitution - Google phishing**
   - Input: `"security@gооgle.com"` (both 'o' characters are Cyrillic 'о' U+043E)
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "The text contains characters from multiple scripts: Latin, Cyrillic."`
     - `CanonicalValue = "security@google.com"`
     - `Findings` contains `MixedScript` and `Homoglyph` entries for positions 10 and 11

7. **Apple account takeover attempt**
   - Input: `"noreply@аpple.com"` (Cyrillic 'а' U+0430 at start of 'apple')
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "The text contains characters from multiple scripts: Latin, Cyrillic."`
     - `CanonicalValue = "noreply@apple.com"`
     - `Findings` contains `MixedScript` and `Homoglyph` entries

8. **Mixed-script rejected by default policy (obvious Greek characters)**
   - Input: `"alerts@παypal.com"` (Greek `π` + `α` in the domain)
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "The text contains characters from multiple scripts: Latin, Greek."`
     - `CanonicalValue = "alerts@παypal.com"`
     - `Findings` contains one `MixedScript` entry covering the full string

9. **Locale override allowing Greek + Latin mixture**
   - Input: `"alerts@παypal.com"`
   - Options: `Locale = "el-GR"`
   - Expected output: `IsSafe = true`, `Reason = ""`, `CanonicalValue = "alerts@παypal.com"`, `Findings = []` because the `latin-greek` profile permits that script pair.

10. **Amazon phishing with fullwidth digit**
   - Input: `"billing@аmazon.com"` (Cyrillic 'а' U+0430 in 'amazon')
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "The text contains characters from multiple scripts: Latin, Cyrillic."`
     - `CanonicalValue = "billing@amazon.com"`
     - `Findings` contains `MixedScript` and `Homoglyph` entries

11. **Bidirectional override in the domain**
   - Input: `"billing@\u202Eexample.com"`
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "Invisible character of category 'Format' found at position 8."`
     - `CanonicalValue = "billing@\u202Eexample.com"`
     - `Findings` contains two entries: one `InvisibleCharacter` (`Position = 8`, `Substring = "\u202E"`), and one `BidirectionalControl` (`Position = 8`, `Substring = "\u202E"`)

12. **Zero-width separator in the local part**
   - Input: `"admin\u200Broot@example.com"`
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "Invisible character of category 'Format' found at position 5."`
     - `CanonicalValue = "admin\u200Broot@example.com"`
     - `Findings` contains one `InvisibleCharacter` entry (`Position = 5`, `Substring = "\u200B"`)

13. **Sophisticated multi-vector attack - homoglyph + invisible character**
   - Input: `"support\u200B@pаypal.com"` (zero-width space after 'support' + Cyrillic 'а' in 'paypal')
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "Invisible character of category 'Format' found at position 7."`
     - `CanonicalValue = "support@paypal.com"`
     - `Findings` includes `InvisibleCharacter` (`Position = 7`) and `MixedScript`/`Homoglyph` entries for the Cyrillic character

14. **Combined zero-width and bidirectional controls**
   - Input: `"admin\u200B@\u202Eexample.com"`
   - Options: omitted
   - Expected output:
     - `IsSafe = false`
     - `Reason = "Invisible character of category 'Format' found at position 5."`
     - `CanonicalValue = "admin\u200B@\u202Eexample.com"`
     - `Findings` includes two `InvisibleCharacter` entries (`Position = 5`, `Substring = "\u200B"` and `Position = 7`, `Substring = "\u202E"`), plus one `BidirectionalControl` entry (`Position = 7`, `Substring = "\u202E"`)

### `GetCanonicalString`

Produces a canonical representation using the same mappings as the detector.

- Input parameter:
  - `Text` (`string`, required)
- Behaviour highlights:
  - Returns the input unchanged when `Text` is `null` or empty.
  - Otherwise normalises via Form KC and rewrites characters using the confusables index, including ASCII mappings.

#### Example combinations

1. **Empty string**
   - Input: `""`
   - Output: `""`

2. **Full-width characters normalised**
   - Input: `"ＦＡＱ"`
   - Output: `"FAQ"` (Form KC strips full-width presentation forms)

3. **ASCII homoglyph rewritten**
   - Input: `"hel1o"`
   - Output: `"hello"` (digit one maps to Latin `l`)

4. **Non-breaking space preserved as visible space**
   - Input: `"user\u00A0name"`
   - Output: `"user name"` (Form KC converts `U+00A0` to a standard space)

5. **Canonical threat token retained**
   - Input: `"paypal-security-center.com"`
   - Output: `"paypal-security-center.com"` (no rewrites performed)

### `RefreshConfusablesData`

Refreshes the in-memory confusables dataset from a URL or supplied bytes.

- Input parameters:
  - `ConfusablesUrl` (`string`, optional, default `https://www.unicode.org/Public/security/latest/confusables.txt`)
  - `ConfusablesContent` (`byte[]?`, optional)
- Behaviour highlights:
  - When `ConfusablesContent` is provided (non-empty), it is treated as UTF-8 encoded text and the download step is skipped.
  - When `ConfusablesUrl` is blank or `null`, the default URL is used.
  - Fails fast on invalid URIs, download errors, or non UTF-8 content, returning `IsSuccess = false` with the exception message.
  - On success, reloads `ConfusablesDatasetLoader` and `ConfusablesIndex`, exposing metadata through the result struct.

#### Example combinations

1. **Default refresh (no arguments)**
   - Expected output: `IsSuccess = true`, `Message = "Confusables dataset refreshed successfully."`, `SourceVersion = "17.0.0"`, `SourceDate = 2025-07-22T05:49:37Z`, `EntryCount = 9981`

2. **Custom URL**
   - Inputs: `ConfusablesUrl = "https://example.org/custom/confusables.txt"`
   - Expected output on success: same shape as default, with `RetrievedAt` reflecting the current time and `SourceVersion`/`SourceDate` parsed from the remote file.

3. **Inline content without download**
   - Inputs: `ConfusablesUrl = null`, `ConfusablesContent = Encoding.UTF8.GetBytes(File.ReadAllText("confusables.txt"))`
   - Expected output: success result with metadata extracted from the provided bytes.

4. **Invalid URL**
   - Inputs: `ConfusablesUrl = "ftp://invalid"`
   - Expected output: `IsSuccess = false`, `Message = "ConfusablesUrl must be an absolute URI."`

5. **Non UTF-8 content**
   - Inputs: `ConfusablesUrl = null`, `ConfusablesContent = new byte[] { 0xFF, 0xFF }`
   - Expected output: `IsSuccess = false`, `Message = "Confusables binary content is not valid UTF-8 text."`
