# Confusables Dataset Maintenance

UnicodeSpoofGuard ships a curated copy of the Unicode Security `confusables.txt`
dataset. The bundled JSON is generated by the `UpdateConfusables` tool and
checked into `data/confusables.json`.

## Update Workflow

1. Ensure you have internet access and the .NET SDK 8.0 or newer installed.
2. Run the updater from the repository root:

   ```
   dotnet run --project tools/UpdateConfusables -- -v
   ```

   This downloads the latest `confusables.txt`, validates its SHA-512 checksum
   (when published by the Unicode Consortium), and rebuilds `data/confusables.json`.

3. Review the diff in `data/confusables.json` and commit it alongside any related
   code changes.

4. Update `CHANGELOG.md` if the new dataset affects detection behaviour.

### Offline / Custom Source

- To regenerate the JSON from a local `confusables.txt` file, pass the
  `--local` switch:

  ```
  dotnet run --project tools/UpdateConfusables -- --local path/to/confusables.txt
  ```

- Use `--output` to direct the JSON to an alternative location.

## CI Freshness Check

The GitHub workflow `confusables-staleness.yml` runs on pull requests and a
weekly schedule. It calls:

```
dotnet run --project tools/UpdateConfusables -- --check
```

The job fails if the bundled data predates the published Unicode dataset or if
checksum verification fails, prompting contributors to refresh the bundle.
